VILX — site oficial
===================

1) vilx-site-completo.html
   Abra com dois cliques. Tudo está dentro deste único arquivo
   (código, estilos, fontes, avatar 3D e todas as fotos).

2) site/
   O site no formato normal para hospedagem:
     index.html   página principal
     assets/      código, estilos, fontes e avatar 3D
     media/       todas as fotos (WebP, em várias resoluções)
     favicon.svg
   Envie o CONTEÚDO desta pasta para a hospedagem (Hostinger, Netlify,
   Vercel, GitHub Pages...). Funciona na raiz ou em subpasta.
   Atenção: o index.html desta pasta NÃO abre com dois cliques, porque
   o navegador bloqueia scripts carregados direto do disco. Para ver no
   computador, use o item 1, ou rode dentro da pasta site:
       npx serve .
   e abra o endereço que aparecer.

3) codigo-fonte/
   Projeto completo (Vite + React + TypeScript) para editar:
       npm install
       npm run dev           (desenvolvimento)
       npm run build         (gera a pasta dist = item 2)
       npm run build:single  (gera o arquivo único = item 1)
   Detalhes, mapa das fotos e pendências em codigo-fonte/README.md.

O player do Spotify precisa de internet; o resto funciona offline.
